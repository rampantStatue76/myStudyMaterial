#### 基础知识

- 对象是不可迭代的，不可以使用for..of获取对象的值
- 可以使用for...in获取对象的键
- 对象的键只能是字符串或者Symbol，否则将强制转换为字符串
- 键值对是无序的，每次打印输出的结果可能不同

#### Object.keys()

获取对象的键，得到所有键组成的一个数组

#### Object.values()

获取对象的值，得到所有的值组成一个数组

#### Object.entries()

把对象转换为二维数组

```javascript
const user = {
  name: "晴晴",
  age: 22,
  city: "成都"
};

console.log(Object.entries(user));
// [
//  ["name", "晴晴"],
//  ["age", 22],
//  ["city", "成都"]
// ]
```
