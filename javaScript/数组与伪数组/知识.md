## 总结

在普通函数中，`arguments` 是一个内置的类数组对象，包含了所有传入的参数，但不能直接使用数组方法；

而 `args` 通常是我们用剩余参数语法 `(...args)` 定义的变量，是一个真正的数组；

相比之下，`args` 更现代、更灵活，也能用于箭头函数中。

## 数组与伪数组的切换

- 扩展运算符 const arr = [...args]
- Array.from(): const arr = Arrya.from(arguments)
- Array.prototype.slice.call(): const arr = Array.prototype.slice.call(arguments)
- const arr = [].slice.call(arguments)

## arguments与args

 **arguments是伪数组对象，且在箭头函数中没有**

```javascript
function add(){
    console.log(arguments)
}
add(1,2,3,4)  //[Arguments] { '0': 1, '1': 2, '2': 3, '3': 4 }
```

**agrs是真数组，通常用来命名剩余参数（ES6）**

```javascript
function demo(...args){
    console.log(args) // [1, 2, 3]
    console.log(Array.isArray(args)) //true
}

demo(1,2,3)
```
