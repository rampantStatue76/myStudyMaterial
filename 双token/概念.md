## 概念

| 类型                    | 作用                  | 有效期                | 存储位置                                 |
| ----------------------- | --------------------- | --------------------- | ---------------------------------------- |
| **Access Token**  | 用来访问接口（API）   | 短（如 15 分钟）      | `memory`或 `localStorage`            |
| **Refresh Token** | 用来刷新 Access Token | 长（如 7 天或 30 天） | 一般放在 `HttpOnly Cookie`或安全存储中 |

**HttpOnly Cookie 是什么？**

是Cookie的一个属性：Set-Cookie: refreshToken=xxxx; HttpOnly; Secure; SameSite=Strict

带 `HttpOnly` 的 Cookie：

* **不能被 JS 访问** （即不能通过 `document.cookie` 读取或修改）；
* **会自动在请求时被浏览器带上** （符合同源策略）；
* **能防止 XSS 攻击窃取 Token** 。

## 常识

项目使用的是双 Token 机制，Access Token 用于短期访问接口，Refresh Token 用于刷新新的 Access Token。这样既能保证接口访问安全，又能避免频繁登录。前端一般会在 axios 拦截器中自动检测 401 状态，通过 Refresh Token 获取新 Access Token，从而实现无感刷新。
