**禁用按钮（最常见且高效）**

在点击后立即将按钮设为禁用状态，等请求完成再恢复：

```javascript
<button :disabled="loading" @click="handleClick">
    {{ loading ? '提交中...' : '提交' }}
</button>
const handleClick = async () => {
  if (loading.value) return
  loading.value = true
  try {
    await submitForm() // 模拟异步请求
  } finally {
    loading.value = false
  }
}
```

**防抖**

频繁的点击，我们只需关注最后一次没被打断的即可，二次封装button组件后统一加上防抖

**自定义指令**

给button组件绑定一个自定义组件

```vue
<button v-prevent-click="3000" @click="submit">提交</button>
```

```javascript
app.directive('prevent-click',{
    mounted(el, binding) {
        const delay = binding.value || 300
        el.addEventListener('click', () => {
            el.disabled = true
            setTimeout(() => {
                el.disabled = false
            }, delay)
        }, delay)
    }
})
```
