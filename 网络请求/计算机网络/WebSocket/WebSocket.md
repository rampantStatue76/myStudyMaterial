## 定义

建立在TCP传输层之上的 **应用层协议**，在TCP之上定义了一套新的“通信语义”，可以让双方持续通信，而不是一次性请求响应

## WebSocket 与 HTTP 的关系

| 对比点       | HTTP                       | WebSocket          |
| ------------ | -------------------------- | ------------------ |
| 连接方式     | 请求-响应                  | 一次握手后保持连接 |
| 方向性       | 单向（客户端- --> 服务端） | 双向（全双工）     |
| 传输层       | TCP                        | TCP                |
| 是否保持连接 | 短连接                     | 长连接             |
